# Fixtures

A fictional roster and certificates; names are made up and the grace period is an example
setting. Planted: a prep cook hired 45 days ago with no card (missing_card), a dishwasher
hired 10 days ago (still in the grace period), a sous chef whose food handler card expired
(expired) and whose manager certificate expires in 16 days (expiring_soon), a server with
no alcohol server certificate (alcohol_cert_missing), Harbor Road's only certified manager
expired in May (no_certified_manager), and an inactive employee who is ignored.
