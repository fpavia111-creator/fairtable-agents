# Fixtures

One fictional month at five fictional locations. Planted: Uptown with food cost, prime
cost, voids and discounts well above the group (food_pct_high, prime_pct_high,
void_pct_high, discount_pct_high), and the airport kiosk with a much lower average check
than the group (avg_check_low; expected for a kiosk, so only watched).
